## 📊 What to Check During URL Inspection

When inspecting each URL, verify:

- ✅ **Status**: "URL is on Google" / "URL is on Bing"
- ✅ **Canonical URL**: Should show `https://curlea.beauty/...` (not netlify.app)
- ✅ **Mobile Usability**: Should pass
- ✅ **Indexing**: Request indexing if not already indexed
- ✅ **Coverage**: No errors should be shown
