================================================================
⚡ QUICK FIX - Hosted Dashboard Shows Empty Tables
================================================================

PROBLEM:
Local dashboard (localhost:8080/analytics) shows data ✅
Hosted dashboard shows empty tables ❌

ROOT CAUSE:
Hosted dashboard is using DIFFERENT Supabase credentials!

================================================================
SOLUTION (2 minutes):
================================================================

Step 1: Copy Environment File
------------------------------
Run this command from project root:

PowerShell:
  Copy-Item .env analytics-backend\analytics-dashboard\.env

Mac/Linux:
  cp .env analytics-backend/analytics-dashboard/.env

Step 2: Verify Supabase Credentials
------------------------------------
Check that .env file has these values:

VITE_SUPABASE_URL=https://vfhxwzcbjdlfmizakvqc.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here

Step 3: Restart Hosted Dashboard
---------------------------------
cd analytics-backend/analytics-dashboard
npm run dev

Step 4: Refresh Browser
------------------------
Hard refresh: Ctrl+Shift+R
Or: Close and reopen browser

DONE! Data should appear! ✅

================================================================
WHAT WAS WRONG:
================================================================

Local dashboard uses:     .env (root folder)
Hosted dashboard uses:    analytics-backend/analytics-dashboard/.env

They were connecting to DIFFERENT databases!

================================================================
VERIFICATION:
================================================================

After fix, BOTH dashboards should show:
  ✅ Same data in all tables
  ✅ Same row counts
  ✅ No errors in browser console (F12)

================================================================
IF STILL EMPTY:
================================================================

1. Check browser console (F12) for errors
2. Check Network tab for API calls to supabase.co
3. Verify .env file is in correct location
4. Make sure you ran "npm run dev" to restart
